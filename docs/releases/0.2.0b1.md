PEDRO 0.2.0b1 is the first public beta for harmonic vibrational mode assignments of molecules embedded in
large ONIOM and QM/MM models. It retains the full-model coupling when describing the target molecule in its
own internal coordinates.

- Full-model F analysis is the default; Fprime and partial-Hessian P conventions remain available.
- Export signed TED, Morino–Kuchitsu diagonal PED, frequencies, intensities, coordinates, and analysis provenance.
  Diagonal PED is not a normalized probability distribution. VEDA-balanced PED applies to isolated molecules.
- Read Gaussian logs/formatted checkpoints, ORCA Hessians, VEDA inputs, and the documented program-independent
  format. Gaussian GVPT2 reading remains optional; the main beta scope is harmonic analysis.
- Use the GUI, CLI, or Python API. The Windows managed installer follows published beta/stable tags, supports
  pinning and offline launch, and preserves the previous active environment if an update fails.
- Include owned examples, VEDA and UniMoVib comparison records, and an owned 614-atom ONIOM benchmark extraction
  check with all 1,836 modes. The full benchmark log is distributed separately from the source repository at
  [dataset DOI 10.5281/zenodo.24213306](https://doi.org/10.5281/zenodo.24213306). Collaborator-owned logs are excluded.

The beta has numerical validation and documented limitations. The weakly coupled water benchmark establishes
handling and energy accounting; it does not demonstrate a changed protein/cofactor assignment. Development
will continue publicly, with publication plans following a convincing application demonstration.

Install the tagged beta with:

```cmd
python -m pip install --upgrade "pedro-ped[gui] @ git+https://github.com/Fisicas/PEDRO@v0.2.0b1"
```
